# Security policy

Chronicler runs a web server bound to `127.0.0.1` only, stores API keys in the operating system keychain and never uploads audio.

If you find a security problem, please do not open a public issue.
Report it privately through [GitHub security advisories](https://github.com/RogerHerazo/chronicler/security/advisories/new).
You will get a reply within a week.
